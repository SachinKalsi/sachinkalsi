## Things I've built

**[constrained-decoding](https://github.com/SachinKalsi/constrained-decoding)** — Forces open-weight LLMs to output exactly one of your taxonomy labels using a trie. No prompt tricks, no post-processing regex — structural guarantee at the token level. Handles multi-label + repeat prevention.

**[LLM-NER-Offset-Generator](https://github.com/SachinKalsi/LLM-NER-Offset-Generator)** — NER training data generation using LLM tool-calling. Gets `start_offset` / `end_offset` right, which is the part most LLM-based annotation pipelines get wrong.

**[annotated-research-papers](https://github.com/SachinKalsi/annotated-research-papers)** — NLP/LLM papers I've read, with notes. An archive rather than a live project.

**[html_tag_annotator](https://github.com/SachinKalsi/html_tag_annotator)** — Chrome extension + ML tool to create training datasets fast — tag HTML elements directly in the browser.

**[web-mark](https://github.com/SachinKalsi/web-mark)** — Chrome extension to highlight and annotate web pages, with optional Google Sheets backup.
